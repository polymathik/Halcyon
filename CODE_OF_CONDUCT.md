# Code of conduct

Halcyon adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. In short:

- Be respectful and assume good intent. Disagree about ideas, not people.
- No harassment, insults, sexualised language or imagery, or personal attacks.
- Don't publish anyone's private information, including the contents of their coding sessions, without permission.
- Accept the maintainer's decisions on moderation. Maintainers may remove, edit or reject comments, commits, issues and other contributions that don't follow this code, and may ban contributors temporarily or permanently.

It applies in all project spaces (issues, pull requests, discussions) and when someone represents the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@sarupurisailalith](https://github.com/sarupurisailalith), by email at the address on that GitHub profile. Reports are handled confidentially. Enforcement follows the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban, permanent ban.
